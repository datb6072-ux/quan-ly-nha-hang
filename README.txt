HỆ THỐNG QUẢN LÝ NHÀ HÀNG ẨM THỰC ĐỒNG QUÊ
Công nghệ: HTML5, CSS3, JavaScript thuần, LocalStorage.

CÁCH CHẠY:
1. Giải nén thư mục QuanLyNhaHang_DongQue.
2. Mở thư mục bằng Visual Studio Code.
3. Cài tiện ích Live Server (khuyến nghị).
4. Nhấn chuột phải index.html -> Open with Live Server.
   Hoặc mở trực tiếp index.html bằng Chrome/Edge.
5. Đăng nhập: admin / 123456.

CHỨC NĂNG:
- Tổng quan, quản lý bàn ăn, thực đơn, gọi món, hóa đơn,
  khách hàng, nhân viên, thống kê doanh thu.
- Thêm/sửa/xóa món ăn; thêm bàn; tạo order; thanh toán;
  xem chi tiết và in hóa đơn.
- Dữ liệu mẫu được khởi tạo lần đầu và lưu trên LocalStorage.

LƯU Ý:
- Đây là bản demo Front-end. Dữ liệu chỉ nằm trên trình duyệt/thiết bị hiện tại.
- Không dùng mật khẩu demo hoặc LocalStorage cho hệ thống kinh doanh thật.
- Muốn nhiều máy dùng chung dữ liệu cần bổ sung Backend và CSDL.
- Có thể xóa dữ liệu demo bằng cách mở DevTools -> Application ->
  Local Storage -> xóa khóa dongque_restaurant_v1.
